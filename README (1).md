## 📖 About

**DigiTools Platform** is a premium digital tools buying website where users can browse, select, and purchase a curated collection of digital productivity tools. From design software to analytics dashboards, the platform offers an intuitive shopping experience with a clean, modern interface.

---

## ✨ Key Features

### 🛒 Smart Cart System
Full-featured shopping cart with add/remove functionality, real-time total calculations, and a smooth checkout experience powered by React-Toastify notifications.

### 📱 Fully Responsive Design
Pixel-perfect responsive layout that adapts seamlessly across mobile, tablet, and desktop screens using Tailwind CSS and DaisyUI components.

### ⚡ Dynamic Product Showcase
Interactive product-cart toggle system with beautifully designed product cards, tag-based categorization (Popular, New, Best Seller), and one-click purchasing.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/digitools-platform.git

# Navigate to the project
cd digitools-platform

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
